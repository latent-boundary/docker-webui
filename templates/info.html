About This Project

This Web UI demonstrates a minimal Docker + Flask application with a built‑in visualization pipeline. It is designed as a foundation for HPC and simulation workflows. This visualization pipeline can be extended to show electric fields, charge density, and phase‑space evolution in future PIC simulations.

What is 1D Particle-In-Cell (PIC)?

PIC is a simulation method used to model plasma by tracking particles and solving electric fields on a grid. Particles move according to the electric field, and their charge updates the field again — forming a self‑consistent loop.

1D PIC Sample Particle Distribution

The image below shows particle positions from a 1D PIC simulation. Each dot represents a particle position in configuration space. Such plots are commonly used to verify uniformity, boundary conditions, and early-time plasma behavior before running full dynamics.

This project serves as a minimal but extensible base for future HPC visualization pipelines.
